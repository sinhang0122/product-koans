## 0. 원칙
- 한인 대상 **한국어 전용**(자동 번역 보류). 컨셉 "Flatmates + 식닷컴".
- **로그인 없이 열람 가능 유지**. 프로필은 필요해진 순간에만.
- **삭제 없이 숨기기(플래그)** 먼저, 원하는 모습이 확실해진 뒤 정리. 과거 삭제 회귀(2026-06) 재발 금지.
- 수정은 Cowork(Fable 5.1) · 커밋/푸시/배포는 Claude Code(Fable 5-high, rules 난항 시 Opus 4.8 max). 배포 순서 functions → rules → hosting.
- 제안은 "KoAus에서 실제 되는 선 + 소요 기간" 기준. 운영 중 사이트 — 되돌리기 어려운 것(데이터 구조·룰·외부 서비스·법 문구)은 **조사 후 확정**.
- Cloud Functions 최소화 정책 유지 — 알림 엔진처럼 꼭 필요한 것만 추가.

## 3. 2단계 — 입구·역할·프로필
- 가입(이메일/구글 → 휴대폰 인증 → 닉네임) 현행 유지.
- **Living 진입 시 "집 구해요 / 세입자 구해요", Work 진입 시 "일 구해요 / 직원 구해요"** 두 버튼. `users/{uid}.roles` 저장, 전환 링크.
- 글은 **집 있는 사람·일자리 주는 사람만** 올림. 집 구하는 사람·일 구하는 사람은 **글이 아니라 프로필**.
- Living = **쌍방**(집주인 → 근처 구하는 사람 프로필 열람, 구하는 사람 → 맞는 방 추천). Work = **구직자에게만** 추천(사장님 쪽엔 아무것도 안 감 → ABN 게이트 불필요).
- 집 구해요 7단계: 지역+동네 3개 → 주당 예산 → 입주일·단기/장기 → 방 조건 → 나에 대해(이름 성 제외·나이대·성별·신분·흡연/반려동물·소개 300자) → 사진(기본 켜짐) → 공개(로그인 사용자) + 알림 동의.
- 일 구해요 8단계: 지역 → 업종(복수)·고용형태 → 가능 요일/시간·시작일·근무 가능 기간(구간) → 비자 종류(워홀 1·2·3년차/학생/영주권·시민/기타)+세컨 일수 필요 → 언어 → 경력 1~3줄(선택) → 자기소개·각오 300자·희망 시급(선택) → 공개(기본 꺼짐) + 알림 동의.
- 프로필 금지 항목: 연락처·이메일·생년월일·여권/비자번호·TFN·도로명. 비자 만료일은 구간만. 원칙 "조건 먼저·신원 나중, 화면당 질문 하나, 단계별 자동 저장, 90초".
- 거리 매칭(Tinder 식): 방 좌표 기준 희망 동네 10km(5/10/20/50 슬라이더) 안 프로필, 예산 겹침·입주일·성별(여성 전용만)·흡연·반려동물 칩, "약 N km" 표시(동네 중심점+오프셋 좌표), 입주일 가까운 순·최근 활동 순. 소규모(수백 건)는 클라이언트 계산, 커지면 geohash.

## 4. 3단계 — 신뢰 장치
- **ABN 확인 라벨**: Cloud Function `verifyAbn`(정부 ABR 무료 JSON, GUID 서버 비밀) → "OO PTY LTD · 등록 상호 · 활성 · 주" 확인 → 글·프로필에 "ABN 확인됨 · 상호"(클릭 시 정부 ABN Lookup). 보증성 문구("KoAus 인증") 금지, 약관에 "등록부 조회 결과 표시, 보증 아님". 한 ABN 다계정 + 지점명 필드(하나로마트: 주마다 ABN 다름 확인). 게이트가 아닌 선택 라벨.
- 세입자 쪽 서류 확인은 보류(후일 선택 배지: RTA 본드 영수증·rates 고지서, 운영자 확인 후 파일 삭제).
- 대리 등록: "KoAus 대리 등록 · 문의는 운영자 전달" 라벨 + **글 주인 넘기기**(운영자 전용 authorUid 변경) — 사장님 가입 시 글·채팅 이관.

## 5. 4단계 — 추천·알림 엔진
- 저장된 조건으로 새 글 매칭 → 이메일. 즉시(10분 내) / 시간당 1통 묶음 / 밤 10시~아침 7시 보류 / 하루 요약 7:30 / 주간 요약 / 글 올린 사람 "N명이 봤어요". 사용자당 하루 3통 상한, 설정에서 즉시·5개 이상·하루 한 번·끄기. 수신 거부·발신자 표기(Spam Act 2003).
- "내가 본 것 제외" 는 서버 저장 필요(계정당 1문서 최근 300개).
- 구현: Firebase 이메일 확장 + 발송 서비스(Brevo/SendGrid/Resend 비교 후 확정) + 매칭 함수.
- 이후: 한인마트 주간 세일 섹션(마트 제공/동의 전단을 AI로 품목·가격 추출 → 검토 → 검색) — 울워스·콜스는 링크 위주, 전단 복제 금지. AI 문의 챗봇은 FAQ+티켓 접수까지만(계정 조치 금지).
