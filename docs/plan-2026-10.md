## 5. 4단계 — 추천·알림 엔진
- 저장된 조건으로 새 글 매칭 → 이메일. 즉시(10분 내) / 시간당 1통 묶음 / 밤 10시~아침 7시 보류 / 하루 요약 7:30 / 주간 요약 / 글 올린 사람 "N명이 봤어요". 사용자당 하루 3통 상한, 설정에서 즉시·5개 이상·하루 한 번·끄기. 수신 거부·발신자 표기(Spam Act 2003).
- "내가 본 것 제외" 는 서버 저장 필요(계정당 1문서 최근 300개).
- 수신 주소: **로그인 이메일로 자동 발송**(확인 절차 없음). 환경설정 "알림 받는 이메일" 칸으로 변경 가능하되, **다른 주소로 바꿀 때만** 확인 메일 1통(버튼 클릭)으로 검증. 동의는 프로필 작성 시 "새 매물 알림 받기" 체크(기본 켜짐), 모든 메일 하단 "알림 끄기" 링크.
- 구현: Firebase 이메일 확장 + 발송 서비스(Brevo/SendGrid/Resend 비교 후 확정) + 매칭 함수.
- 이후: 한인마트 주간 세일 섹션(마트 제공/동의 전단을 AI로 품목·가격 추출 → 검토 → 검색) — 울워스·콜스는 링크 위주, 전단 복제 금지. AI 문의 챗봇은 FAQ+티켓 접수까지만(계정 조치 금지).

## 9. 확정 문구·어투
- 사이트 안내 문구는 **"~다/~까"(합쇼체)** 로 통일. "~요" 금지. 2단계 폼 작업 때 전체 정비.
- 검색 결과 상단에 "없다"는 안내 문장을 두지 않는다. 가까운 순으로 매물을 보여주고 카드마다 "Southport에서 4km" 거리만 표기.
- 목록 끝: "더 이상 표시할 매물이 없습니다. 범위를 늘리시겠습니까?" → 버튼 "범위 늘리기"
- 알림(후순위): 문장 없이 버튼 "Southport 새 매물 알림 받기"
- 알림 조건은 동네 묶음(최대 3개, 각 5km). 벗어난 동네 검색 시 "Chermside도 알림에 추가할까요?" 칩. 메일은 동네별 묶음 + 거리 표기.

- 글쓰기 폼 개편(2단계): 쉐어 필수 5개(동네·주당 가격·방 종류·입주일·사진), 단일 선택 칩(방 종류·욕실·성별·최소 거주), 예/아니오 칩은 "보통과 다른 것만"(빌 포함·가구 없음·에어컨·주차·반려동물·커플·흡연·아이), 숫자(본드, 거주 인원·구성), 연락은 채팅 기본 + 전화·카톡·이메일 중 선택. 라벨 옆 "(필수)/(선택)" 일반 글씨. 구인: 필수 4개 + 칩(비자 가능·세컨/써드 일수 인정·픽업·숙소·한국어 가능·초보 가능·주말).
- 홈 상단 네모 두 칸(1단계에 포함): "쉐어 · 렌트"(작게 Living) / "구인구직"(작게 Work) → accom.html / jobs.html. 탭바 영상 탭 제거(1단계).
- **빈 채팅방 lastMsgAt 누락(기존 데이터 이슈, 2026-10-11 배포 검증 중 발견)**: 메시지 0건인 방은 `lastMsgAt`이 없어 `orderBy(lastMsgAt)` 목록에서 빠짐. 방 생성 시 `lastMsgAt: serverTimestamp()` 추가로 해결(rules create는 이미 허용: `!('lastMsgAt' in data()) || == request.time`). 생성 지점(글 상세 "채팅하기")만 고치면 됨. 기존 빈 방은 건드리지 않음.
