3. 안내 카드 통일(인터넷 끊김·자동 로그아웃·저장 완료): 흰 카드·얇은 테두리·모서리 둥근 사각형·14px + 왼쪽 점(11-17 사용자 선택 — 후보 B), 상단바 아래. 빨강·초록 그라데이션 삭제. 긴 문구는 줄바꿈. 자동 로그아웃은 1시간 → 하루.

5. 구인구직 글쓰기·상세 필터·글 상세, 영상 등록 창이 떠 있을 때 뒤 목록이 같이 움직이던 것(배경 잠금). 닫을 때 목록이 맨 위에서 훑어 내려오던 것도 수정.
6. 글자 크게(가+ / 가++)에서 상단바가 깨지던 것. 360px 이하에서 '로그인' 이 두 줄로 꺾이던 것.
7. 보안
   1. 목록 카드에 글의 id·가격·날짜가 이스케이프(특수문자를 글자로만 보이게 하는 처리) 없이 들어가던 곳 104줄(11개 페이지). 글 주인이 자기 글 문서를 직접 고쳐 다른 방문자 화면에서 스크립트를 실행시킬 수 있었습니다(재현 확인).
   2. 일반 글에 `ext: true, outUrl: 'javascript:…'` 를 심으면 외부 글 카드로 그려지고 그 주소로 이동하던 것. 이제 `ext_posts` 에서 읽은 글만 외부 글로 취급합니다.

8. 문의하기: 실패하면 이유와 [메일로 보내기] 가 나옵니다.
9. 가입 비밀번호 안내("6자 이상")를 실제 검사(영문 대·소문자 + 숫자 + 특수문자 10자 이상)와 맞춤.
10. 파비콘(브라우저 탭 아이콘)·홈 화면 아이콘·매니페스트(manifest, 홈 화면에 추가할 때 쓰는 앱 정보 파일) 추가.
11. 읽기 쉽게: 제목 단어 단위 줄바꿈, 마이페이지 탭 단어 단위 줄바꿈, 닫기(✕) 36px, 환경설정 작은 버튼 12px.

## 1. 다른 서비스와 비교

### 1-1. 각 서비스가 잘하는 것(공식 앱 소개·제품 페이지 기준)

1. Flatmates(쉐어)
   1. 방 올린 사람과 방 구하는 사람이 서로 프로필을 보고 먼저 연락합니다.
   2. 조건에 맞는 새 글 알림.
   3. 자체 메시지 — 연락처를 언제 공개할지 본인이 정합니다.
   4. 글 검수 팀, 유료 노출(Boost, Spotlight).
2. realestate.com.au(렌트)
   1. 저장한 검색 + 새 매물 알림.
   2. 인스펙션(집 보러 가기) 일정 관리.
   3. 한 번 만든 신청서로 여러 집에 지원.
   4. 지도, 주변 학교, 가격 이력. 2026년에 AI 검색(말로 찾기) 추가.
3. SEEK(구인)
   1. 프로필·이력서를 저장해 두고 빠르게 지원.
   2. 추천 일자리와 "왜 나와 맞는지" AI 요약.
   3. 인증된 자격 표시(영어 능력 등).
   4. 고용주 쪽은 지원자 검색·관리.

### 1-2. KoAus 가 이미 가진 것

1. 쉐어·렌트·구인을 한 계정으로. 한국어.
2. 구하는 사람 프로필(Living / Job)과 집주인·사장님이 먼저 메시지 보내기.
3. 지도 + 목록, 주(State)별 보기.
4. 다른 한인 사이트 글 모아 보기(선브리즈번).
5. 조건 맞는 새 글 알림 — 코드는 완성, Resend 키가 없어 아직 안 나갑니다.
6. 세컨·써드 비자 카운트 필터 같은 워홀 맞춤 항목.

### 1-3. 사이트(PC) 기준 장단점

1. 장점: 지도와 목록을 같이 보기 좋고, 필터가 충분합니다. 세 게시판 구조가 같아 배우기 쉽습니다.
2. 단점
   1. 글마다 정보가 들쭉날쭉합니다. 보증금·노티스·빌 포함 여부가 본문 안에만 있어 필터로 못 거릅니다.
   2. 믿을 수 있는 글인지 한눈에 안 보입니다. 휴대폰 인증을 받아야 글을 쓰는데 카드에는 표시가 없습니다.
   3. 알림이 아직 안 나가서 다시 올 이유가 약합니다.

### 1-4. 모바일 기준 장단점

1. 장점: 하단 탭바, 지도 풀스크린, 카드 넘겨 보기가 앱처럼 동작합니다.
2. 단점
   1. 푸시 알림이 없습니다(메일만 예정).
   2. 작은 글자(11px 라벨)와 작은 버튼(36px 미만)이 여러 곳에 있습니다.
   3. 글쓰기 폼이 길고 [등록하기] 가 맨 아래에 있습니다.
   4. 안드로이드 뒤로 가기로 창이 닫히지 않고 페이지가 넘어갑니다.

### 1-5. 손님 입장에서 먼저 키울 것(지금 구조로 가능한 것만)

1. 알림 켜기 — Resend 키 등록 뒤 functions:default 배포. 세 서비스 모두 "저장한 조건 → 알림"이 다시 오게 만드는 핵심입니다.
2. 믿음 표시 — 카드와 프로필에 "휴대폰 인증" 표시, 글 올린 지 며칠인지, 사기 주의 안내. 규칙·데이터는 이미 있어 화면만 붙이면 됩니다.
3. 글 품질 — 쉐어·렌트 글쓰기에 보증금·노티스·미니멈·빌 포함을 칸으로 받기. AI 글 다듬기(6장)와 같이 하면 효과가 큽니다.
4. 구인 글에서 "내 프로필 보내기" — Job 프로필이 있으니 채팅 첫 메시지로 프로필을 한 번에 보내는 버튼(SEEK 의 빠른 지원에 해당).
5. 인스펙션 약속 — 채팅에 "보러 갈 수 있는 시간" 빠른 답장 버튼.
6. 앱 푸시 — 5장 앱 단계 3.

KoAus 가 이기는 자리는 "한국어 · 워홀 맞춤 · 쉐어와 일자리를 한 번에 · 무료"입니다. 큰 서비스 기능을 다 따라가기보다 1~3번을 먼저 하는 쪽을 권합니다.

- 목록 카드의 그림 칸: 사진이 없는 글(다른 사이트에서 가져온 글 포함)은 그림 칸 없이 제목 · 가격 줄만. 사진을 등록한 글만 사진이 보인다(쉐어 · 렌트 · 구인, 쉐어 · 렌트의 지도 아래 칸 포함).
- 구인 지도에서 같은 자리의 글이 묶인 표시를 누르면 뜨는 작은 카드: 가방 그림 칸을 뺐다.
- 다른 사이트 글의 스크립트는 `koaus-ext.js?v=1128a` 로 싣는다. 카드 높이를 푸는 규칙은 세 화면에 바로 적었다(style.css 캐시).
- 건드리지 않은 것: 업소록(맛집 · 미용 · 정비 · GP · 트레이드 · 포인트) 목록의 카드.

## 11-28b 에 처리한 것

- 아래 탭: 홈 · 저장 · 최근 본 · 채팅 · 마이 다섯만('프로필' 탭 숨김).
- 가격 범위: 쉐어 · 렌트 모두 $0 ~ $9999, 위쪽 끝은 제한 없음 — 슬라이더의 끝값을 넘는 글이 처음부터 빠지던 것(11-27b 에 남겨 둔 것)이 풀렸다.
- 가격대 막대그래프: 상세 필터의 가격 위에, 지금 보는 지역 · 조건의 글 수를 가격대별로. 눈금은 그 글들의 가격대에 맞춘다(새 파일 `koaus-price-range.js`).
- 쉐어 최근 검색 기록의 글자에 늘 붙던 "≤$990"이 없어졌다(위쪽 제한이 없으면 가격을 적지 않는다).
- 카드의 동네 이름: 쉐어 · 렌트의 KoAus 글 카드 가격 옆에 동네 이름(사진이 있든 없든).
- 위치 비공개 주소 줄이기(redactAddress): 동네 이름에 길 낱말이 든 곳이 잘려 저장되던 것을 고침 — St Lucia(→ Lucia) · St Kilda · St Leonards · Kelvin Grove(→ Grove) · Ferny Grove · Petrie Terrace · Lane Cove(→ Cove) 등. 쉼표 없이 적은 주소에서 길 낱말이 두 번 나오는 경우(Lane Cove Rd Macquarie Park → 전에는 "Park")와 "St."의 마침표도 같이.

### 11-28b 에서 찾았지만 남겨 둔 것

- 이미 "Lucia QLD 4067"처럼 잘려 저장된 글은 그대로다(정확한 주소는 글쓴이만 읽을 수 있어 코드로 못 고친다). 글쓴이가 수정 화면에서 다시 저장하면 바뀐다.
- 길 낱말로 끝나는 동네 가운데 목록(_SUBURB_KEEP)에 없는 곳(예: Elizabeth Grove SA · Park Avenue QLD)은 여전히 마지막 낱말만 저장된다 — 알게 되면 목록에 더한다.
- 주소를 공개로 두고 쉼표 없이 손으로 적은 주소(예: 12 Mains Rd Sunnybank QLD 4109)는 카드의 동네 자리에 길 이름까지 나온다(Mains Rd Sunnybank).
- 마이(mypage) · 설정(settings) 화면에는 아래 탭이 없다(11-15 에도 그랬다 — 이번에 바꾸지 않았다).

## 11-28c 에 처리한 것

- 목록 순서: KoAus 에서 쓴 글은 쓴 지 7일 동안 다른 사이트에서 가져온 글보다 위(쉐어 · 렌트 · 구인). 그 안에서는 새 글부터, 7일이 지나면 전처럼 시간순.
- 7일 안의 글이 실시간 창(최근 20건)보다 많으면 그만큼 더 불러온다(한 번에 20건, 많아야 3번) — 7일 안의 글이 목록에서 빠지지 않게.
- 지도 보기에는 광고 자리가 보이지 않는다: 히어로 배너 · 전광판 · 상단 노출 글. PC 에서는 셋이 지도 위에 남아 있었고 지도는 첫 화면 아래로 밀려 있었다 — 이제 지도가 첫 화면에 들어온다.

### 11-28c 에서 찾았지만 남겨 둔 것

- 글 만들기(create) 규칙이 `createdAt == request.time` 을 강제하지 않는다(쉐어 · 렌트 · 구인). 수정으로 바꾸는 것은 11-21 에 막았지만, 만들 때는 인증한 회원이 직접 앞선 시각을 넣을 수 있고 그 글은 시간순 목록의 앞에 오래 남는다. 화면은 하루 넘게 앞선 시각을 7일 묶음에 넣지 않는 것까지만 했다. 다음 규칙 묶음에서 create 에 `createdAt == request.time` 을 넣는다(화면은 이미 `serverTimestamp()` 를 보낸다).
- 같은 글을 지우고 다시 올리면 다시 7일 동안 위에 온다(하루 4건 한도 안에서). 글이 늘어 문제가 되면 날 수를 줄이거나(`KOAUS_FIRST_DAYS`), 위에 두는 건수에 한도를 둔다.
- 스스로 더 불러오는 것은 80건까지다. 한 게시판에 7일 동안 쓴 글이 그보다 많아지면 나머지는 목록 끝의 › 를 눌러야 들어온다.
- `style.css` 는 주소에 v 가 없다(한 시간 캐시) — 지도 보기의 광고 숨김은 다녀간 사람에게 길어야 한 시간 늦게 걸린다.
- 홈의 작은 광고 자리(`#adSlot`)는 코드에 그대로 있다(사용자 결정: 일단 쓰지 않는다 — `ads` 에 문서를 올리지 않으면 뜨지 않는다).
