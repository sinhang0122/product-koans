6. 글자 크게(가+ / 가++)에서 상단바가 깨지던 것. 360px 이하에서 '로그인' 이 두 줄로 꺾이던 것.
7. 보안

8. 문의하기: 실패하면 이유와 [메일로 보내기] 가 나옵니다.
9. 가입 비밀번호 안내("6자 이상")를 실제 검사(영문 대·소문자 + 숫자 + 특수문자 10자 이상)와 맞춤.

## 1. 다른 서비스와 비교

### 1-1. 각 서비스가 잘하는 것(공식 앱 소개·제품 페이지 기준)

1. Flatmates(쉐어)
   1. 방 올린 사람과 방 구하는 사람이 서로 프로필을 보고 먼저 연락합니다.
   2. 조건에 맞는 새 글 알림.
   3. 자체 메시지 — 연락처를 언제 공개할지 본인이 정합니다.
   4. 글 검수 팀, 유료 노출(Boost, Spotlight).
2. realestate.com.au(렌트)
   1. 저장한 검색 + 새 매물 알림.
   2. 인스펙션(집 보러 가기) 일정 관리.
   3. 한 번 만든 신청서로 여러 집에 지원.
   4. 지도, 주변 학교, 가격 이력. 2026년에 AI 검색(말로 찾기) 추가.
3. SEEK(구인)
   1. 프로필·이력서를 저장해 두고 빠르게 지원.
   2. 추천 일자리와 "왜 나와 맞는지" AI 요약.
   3. 인증된 자격 표시(영어 능력 등).
   4. 고용주 쪽은 지원자 검색·관리.

### 1-2. KoAus 가 이미 가진 것

1. 쉐어·렌트·구인을 한 계정으로. 한국어.
2. 구하는 사람 프로필(Living / Job)과 집주인·사장님이 먼저 메시지 보내기.
3. 지도 + 목록, 주(State)별 보기.
4. 다른 한인 사이트 글 모아 보기(선브리즈번).
5. 조건 맞는 새 글 알림 — 코드는 완성, Resend 키가 없어 아직 안 나갑니다.
6. 세컨·써드 비자 카운트 필터 같은 워홀 맞춤 항목.

### 1-3. 사이트(PC) 기준 장단점

1. 장점: 지도와 목록을 같이 보기 좋고, 필터가 충분합니다. 세 게시판 구조가 같아 배우기 쉽습니다.
2. 단점
   1. 글마다 정보가 들쭉날쭉합니다. 보증금·노티스·빌 포함 여부가 본문 안에만 있어 필터로 못 거릅니다.
   2. 믿을 수 있는 글인지 한눈에 안 보입니다. 휴대폰 인증을 받아야 글을 쓰는데 카드에는 표시가 없습니다.
   3. 알림이 아직 안 나가서 다시 올 이유가 약합니다.

### 1-4. 모바일 기준 장단점

1. 장점: 하단 탭바, 지도 풀스크린, 카드 넘겨 보기가 앱처럼 동작합니다.
2. 단점
   1. 푸시 알림이 없습니다(메일만 예정).
   2. 작은 글자(11px 라벨)와 작은 버튼(36px 미만)이 여러 곳에 있습니다.
   3. 글쓰기 폼이 길고 [등록하기] 가 맨 아래에 있습니다.
   4. 안드로이드 뒤로 가기로 창이 닫히지 않고 페이지가 넘어갑니다.

### 1-5. 손님 입장에서 먼저 키울 것(지금 구조로 가능한 것만)

1. 알림 켜기 — Resend 키 등록 뒤 functions:default 배포. 세 서비스 모두 "저장한 조건 → 알림"이 다시 오게 만드는 핵심입니다.
2. 믿음 표시 — 카드와 프로필에 "휴대폰 인증" 표시, 글 올린 지 며칠인지, 사기 주의 안내. 규칙·데이터는 이미 있어 화면만 붙이면 됩니다.
3. 글 품질 — 쉐어·렌트 글쓰기에 보증금·노티스·미니멈·빌 포함을 칸으로 받기. AI 글 다듬기(6장)와 같이 하면 효과가 큽니다.
4. 구인 글에서 "내 프로필 보내기" — Job 프로필이 있으니 채팅 첫 메시지로 프로필을 한 번에 보내는 버튼(SEEK 의 빠른 지원에 해당).
5. 인스펙션 약속 — 채팅에 "보러 갈 수 있는 시간" 빠른 답장 버튼.
6. 앱 푸시 — 5장 앱 단계 3.

KoAus 가 이기는 자리는 "한국어 · 워홀 맞춤 · 쉐어와 일자리를 한 번에 · 무료"입니다. 큰 서비스 기능을 다 따라가기보다 1~3번을 먼저 하는 쪽을 권합니다.

## 3. 모바일 화면 — 남은 것

1. 글쓰기 창의 [등록하기] 가 맨 아래(2,500px 지점)에 있어 끝까지 내려야 합니다. 상세 필터처럼 아래 고정 권장.
2. 마이페이지·환경설정·보안 페이지에는 하단 탭바가 없습니다. 탭바의 '마이'로 들어가면 탭바가 사라집니다.
3. 대화방에서 메시지 목록 끝까지 가면 페이지 전체가 같이 밀립니다(이중 스크롤).
4. 36px 보다 작은 버튼: 전광판 ‹ ›(26px), 대화방 차단·신고·나가기(31px), List/Map View(32px), ← 홈으로(30px), 프로필 '편집'(27px).
5. 12px 보다 작은 글자: NOTICE 표시(9.5px), 외부 글 출처(10px), 탭바 이름(10.5px), 카드 보조 정보·입력칸 이름(11px).
6. 짧은 등록 창은 끝낼 때까지 닫을 수 없습니다(의도한 동작). 급한 사용자는 갇혔다고 느낄 수 있습니다.
7. 안드로이드 뒤로 가기로 창이 닫히지 않습니다(앱 단계 2에서 필요).
8. 주소 자동완성 목록이 터치 기기에서 어긋날 수 있어 보정을 넣었습니다. 실제 휴대폰에서 구인구직 글쓰기 주소 칸을 한 번 확인해 주세요.

확인하지 못한 것: 사파리·파이어폭스에서의 글자 크게, 실제 휴대폰에서의 홈 화면 추가 동작.

## 4. 보안 — 남은 것(규칙을 건드려야 해서 따로 묶음)

| 순위 | 문제 | 고치는 법 |
|---|---|---|
| 높음 | 글 수정(update) 때는 규칙이 칸의 종류를 다시 검사하지 않습니다. 화면 쪽은 11-15a 에서 막았지만 규칙에서도 막아야 합니다. | 바뀌는 칸만 검사(가격은 숫자, 모르는 칸 추가 금지) + 테스트 추가 |

| 중간 | 카카오톡 링크 칸에 아무 https 주소나 넣을 수 있습니다(가짜 로그인 페이지 유도). | `https://open.kakao.com/` 으로 시작하는 주소만 |

## 6. AI — 글 다듬기와 챗봇

1. 쓸 모델: Claude Haiku 5.5(`claude-haiku-5-5`). 입력 100만 토큰당 US$0.10, 출력 US$0.50(2026-11 문서 기준). 글 한 번 다듬는 데 0.1센트도 안 듭니다.
2. 글 다듬기
   1. 글쓰기 창의 본문 아래 [AI로 다듬기] → 맞춤법·줄바꿈·빠진 항목 정리 → 전·후를 보여 주고 [적용].
   2. 가격·날짜·주소·연락처는 바꾸지 않게 하고, 없는 사실은 만들지 않게 합니다.
   3. 인증 회원만, 하루 10번.
3. 챗봇(도움말)
   1. 자주 묻는 질문·이용 가이드 안에서만 답합니다.
   2. 비자·법률·세금은 답하지 않고 공식 사이트를 안내합니다(호주에서는 등록되지 않은 사람이 이민 조언을 하면 안 됩니다).
   3. 모르면 "운영자에게 전달" → 문의함에 쌓이고, Resend 가 켜지면 메일로도 갑니다.
4. 필요한 것
   1. Claude 콘솔에서 API 키를 만들어 터미널에서 `npx firebase functions:secrets:set ANTHROPIC_API_KEY` (채팅에 붙이지 않기).
   2. 개인정보처리방침에 "글 다듬기·챗봇에 입력한 내용은 Anthropic(미국)의 AI 로 처리됩니다" 한 줄.
   3. 새 함수 묶음(`functions:ai`) 배포 허락.
